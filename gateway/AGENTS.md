# Gateway 开发规范

## 原则

- 如果有开源代码实现（必须权威），不允许自己造轮子。
- 经验证并固定版本的权威第三方源码以原样可追溯为准，本规范不得反向要求修改其实现；项目自有适配代码仍须遵守本规范。
- 必须严格按照官方文档要求，做最小实现。
- 能一行代码完成绝对不写两行代码。
- 代码安全与质量必须严格符合标准。
- 语义必须精准，不允许冗余。
- 不允许预留兼容壳。
- 代码职责与分层必须清晰，不允许反向依赖。
- 必须符合高内聚、低耦合的原则。
- 不许薄封装。
- 不允许因测试注入及便利影响真实业务代码的设计逻辑，做冗余封装层，降低代码可读性。
- 如果第3条和第5，10条冲突，优先第5，10条。
